# Proyecto Tienda Virtual — Grupo 03

**SENA · ADSO · Ficha 3239188**
**Integrantes:** Sebastián Calderón Briñez, Luis Alfredo Corrales Arrieta, Juan José Cuéllar Rojas
**Instructor:** Carlos Julio Cadena

Sistema de tienda virtual de productos de tecnología con dos canales de venta, presencial/telefónico y en línea, sobre un mismo catálogo, inventario, gestión de pedidos, domicilios y facturación. Tiene 6 roles: Administrador, Vendedor, Encargado de inventario, Encargado de facturación, Domiciliario y Cliente.
